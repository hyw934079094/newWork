# 故事页面画面组与图文间距设计说明

> 状态：已确认（待实现）  
> 日期：2026-08-14  
> 分支策略：在 `master` 上实现（随篇章/故事页面模块落地）  
> 前置：故事系列首期已落地；本规格约束后续「篇章 → 页面 → 内容」实现

## 1. 背景与目标

故事与篇章会关联插图素材，以「文字 + 对话 + 图片」呈现一个画面。图文既不能分离太远（失去同画面感），也不能贴死（拥挤难读）。

需求基线已有可排序内容块（标题、正文、对话、插画等）。本规格补充：

1. **阅读形态**：竖向滚动。  
2. **画面组（BEAT）**：把「一张主插画 + 相关文字/对话」捆成一组。  
3. **间距档位**：组外疏、图文中、组内文紧，解决远近问题。  
4. **与篇章模块边界**：树形 CRUD 另做，但必须遵守本规格。

## 2. 已确认决策

| 项 | 决策 |
|----|------|
| 阅读形态 | 竖向滚动（非翻页画册） |
| 图文归属 | 画面组 BEAT + 独立块 |
| 组内布局 | 上图下文；首期不做左右分栏 |
| 组内插画数 | 恰好 1 张主插画 + 0..n 子块（BODY/DIALOGUE） |
| 数据模型 | 方案 1：顶层项 = 独立块 \| 画面组（含 cover + 子块） |
| 管理端 | 时间线编辑 + 与阅读端共用间距变量预览 |
| 非目标（首期） | 左右分栏、组内多图、绝对定位、视频块 |

## 3. 内容模型

### 3.1 故事页面

- 隶属于篇章模块中的「故事页面」实体（具体表结构在篇章计划中定义）。  
- 页面内容 = **有序顶层项**列表。

### 3.2 顶层项类型

| 类型 | 说明 |
|------|------|
| `TITLE` | 独立标题块 |
| `BODY` | 独立正文（过场叙述等，可不配图） |
| `DIVIDER` | 分隔 |
| `BEAT` | 画面组 |

（未来可扩展；视频等首期不做。）

### 3.3 画面组 BEAT

| 字段 | 规则 |
|------|------|
| `coverAssetId` | 必填；引用 NORMAL 素材；硬删该素材前须 409（与系列封面同类检查） |
| `children` | 有序子块 0..n；类型仅 `BODY` / `DIALOGUE` |
| 布局 | 固定：插画在上，子块在下 |
| 拖拽 | 整组作为顶层项上下移动；组内子块可单独排序 |

### 3.4 独立块与 BEAT 的选用

- 需要「配图的同一画面」→ 必须用 BEAT。  
- 无配图的过场文字 → 顶层 `BODY` 即可。  
- 禁止把「相关配图」与「相关正文」拆成两个相距很远的顶层项却期望读者当成同一画面——应收入同一 BEAT。

## 4. 间距与呈现

使用 CSS 变量（数值可在实现时微调，语义不可改）：

| 变量 | 建议值 | 用途 |
|------|--------|------|
| `--gap-beat` | 40–48px | 顶层项之间（组与组、组与独立块）— **疏**，画面分界 |
| `--gap-figure-text` | 14–16px | BEAT 内插画与第一段文字之间 — **中**，相关不挤 |
| `--gap-inline` | 8–10px | BEAT 内子块之间 — **紧** |

其它呈现约定：

- 阅读栏最大宽度适中（实现时定具体 px）；插画宽度跟随阅读栏。  
- 首期不做文字环绕、不做图文左右混排。  
- 管理端预览与使用端阅读必须共用同一套间距变量，避免「编读不一致」。

## 5. 管理端编排

- 时间线式编辑器：新增顶层「独立块」或「画面组」。  
- 画面组卡片：选择封面（素材单选挑选，对齐系列封面交互）+ 编辑子块列表。  
- 整组拖拽排序；组内子块排序。  
- 即时预览区应用 §4 间距。

## 6. 与篇章模块的关系

本规格**不**单独实现系列→篇章→章节→页面树；该树在「篇章/内容块」实现计划中完成，并须：

- 页面内容结构符合 §3；  
- 渲染/预览符合 §4；  
- 素材硬删检查覆盖 BEAT 封面引用。

可将本文件列为篇章模块 Spec 的依赖。

## 7. 验收标准（实现篇章页面时）

1. 竖滚页面中，BEAT 呈现为上图下文；组外间距明显大于组内图文间距。  
2. 拖动整组时图文不拆散；组内可增删排序 BODY/DIALOGUE。  
3. BEAT 封面素材硬删被引用时 409。  
4. 管理端预览与阅读端间距一致（同变量）。

## 8. 非目标

- 翻页式固定一屏布局（路线图若要做，另开规格）  
- 组内多图、左右分栏模板、绝对坐标排版  
- 视频内容块  
- 本规格单独交付可运行功能（无篇章树则仅文档约束）
