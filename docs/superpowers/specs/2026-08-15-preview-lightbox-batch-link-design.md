# 篇章预览灯箱 + 素材批量关联 设计说明

> 状态：已确认  
> 日期：2026-08-15  
> 分支：`master`

## 1. 背景与目标

1. **篇章整篇预览**中的图片（篇章封面、画面组插画）点击后无法看大图。  
2. 大量无关联素材需逐条在属性区挂关联，效率低。

目标：

- 整篇预览内图片可点击打开全屏灯箱，点空白关闭。  
- 素材工作台支持多选后弹窗一次性覆盖关联（含取消关联）。

## 2. 已确认决策

| 项 | 决策 |
|----|------|
| 预览范围 | 仅篇章整篇预览必做；通过共用 `PagePreview` 使单页预览一并受益 |
| 灯箱交互 | 与系列封面一致：点图开、点遮罩关；本期不做滚轮缩放 |
| 批量目标 | 弹窗内选关联类型 + 具体对象（不依赖当前筛选） |
| 已有关联 | 一律覆盖为弹窗所选 |
| 取消关联 | 弹窗支持 `linkType=NONE`（批量取消） |
| API | 新增 `PUT /api/assets/batch-link`，复用既有 `applyLinks` 互斥规则 |

## 3. 篇章预览灯箱

### 3.1 交互

- `ArcPreview`：篇章封面可点 → 灯箱。  
- `PagePreview`：`BEAT` 封面图可点 → 灯箱（`coverAssetId` 存在时）。  
- 灯箱：`Teleport` 全屏遮罩 + 居中大图；点遮罩关闭；点图片不关。

### 3.2 非目标

- 滚轮缩放、左右翻页、人物预览改灯箱（另案）。

## 4. 批量关联

### 4.1 API

`PUT /api/assets/batch-link`

Request body：

```json
{
  "assetIds": [1, 2, 3],
  "linkType": "CHARACTER",
  "seriesIds": [],
  "arcIds": [],
  "characterIds": [10]
}
```

| 字段 | 规则 |
|------|------|
| `assetIds` | 非空；去重；须存在且为 NORMAL（回收站素材 → 400） |
| `linkType` | `NONE` \| `SERIES` \| `ARC` \| `CHARACTER`，必填 |
| ids 列表 | 与单条更新相同：SERIES/ARC/CHARACTER 要求对应 ids 非空；NONE 时三类清空 |

行为：

- 对每个 `assetId` 调用与单条更新相同的 `applyLinks`（覆盖）。  
- 同一事务；任一条失败则整批回滚。  
- 响应：更新后的 `Asset[]`（hydrate），顺序与请求 `assetIds` 去重后顺序一致。

### 4.2 工作台 UI

- 缩略图增加勾选（多选集合与当前「编辑选中」独立：勾选用于批量；单击缩略图主体仍切换右侧编辑）。  
- 工具栏：「批量关联」（`checkedIds.length > 0` 可点）、「清空选择」。  
- 弹窗：关联类型 + 条件字段（同右侧表单）；确认后调 batch-link；成功提示「已关联 N 项」；刷新列表并清空勾选。

### 4.3 非目标

- 按当前筛选自动填弹窗（可选增强，本期不做）。  
- 部分成功 / 跳过已关联。

## 5. 验收要点

1. 整篇预览：点封面与画面组图 → 大图；点空白关。  
2. 勾选多个无关联素材 → 弹窗挂人物/系列/篇章 → 列表与右侧属性均为新关联。  
3. 勾选已有关联素材 → 批量改绑 → 旧关联被覆盖。  
4. 弹窗选「无」→ 选中素材变为无关联。  
5. `assetIds` 空或非法 link → 400；含回收站 id → 400 且无部分写入。
