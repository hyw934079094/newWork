# 人物身高与素材挑选优化设计说明

> 状态：已确认（待实现）  
> 日期：2026-08-14  
> 分支策略：在 `master` 上实现

## 1. 背景与目标

人物编辑弹窗中「从素材库指定」目前是纯文字多选下拉，素材变多后难以辨认与定位。同时人物缺少身高字段；删除人物时若仅关联已进回收站的素材，界面显示无素材，删除却报 409。

本期目标：

1. **人物身高**：可选整数厘米字段，列表可读展示。  
2. **素材挑选**：人物编辑内用可筛选、带缩略图的二级弹窗替换下拉。  
3. **删除一致**：删人物时只被 NORMAL 关联挡住；DELETED 幽灵关联自动清理。

## 2. 已确认决策

| 项 | 决策 |
|----|------|
| 范围 | 仅人物编辑「从素材库指定」（不做本体/组合统一组件） |
| 身高存法 | `height_cm` 整数厘米，可空；展示「168 cm」 |
| 挑选筛选 | 分类下拉 + 关键字（显示名）；不做人物关联筛 |
| 挑选交互 | 二级弹窗 + 缩略图网格多选 |
| 确定后写库 | 确定只更新本地已选；仍点「保存关联」提交（与现网一致） |
| 删人物 | 仅 NORMAL 关联 → 409；仅 DELETED → 清 rel 后删人 |
| 回收站断链 | 本期不做（素材进回收站不自动断人物关联） |
| 分页 | 本期不做 |
| 实现路径 | 人物页内嵌弹窗 + 复用 `listAssets`；不抽通用组件、不加专用缩略图 API |

## 3. 人物身高

### 3.1 数据

- 表：`character_profile`  
- 列：`height_cm INT NULL`（COMMENT 建议：身高厘米）  
- Flyway：`V5__character_height_cm.sql`

### 3.2 API

- 创建/更新请求与人物 JSON 增加 `heightCm`（Integer，可空）  
- 有值时服务端校验：整数且 ∈ [1, 300]；否则 400  
- 列表/详情原样返回

### 3.3 UI

- 人物编辑表单：输入「身高 (cm)」，可空  
- 列表列：有值显示 `{n} cm`，空显示 `-`  
- 本期不做按身高筛选

## 4. 素材挑选弹窗

### 4.1 入口

- 人物编辑「人物预览素材」区：去掉纯文字 `el-select`  
- 按钮「从素材库指定」打开二级 `el-dialog`（约 720–800px）  
- 已关联缩略图区、上传预览图、「保存关联」保持不变

### 4.2 筛选与数据

- 顶栏：分类（含「全部分类」）+ 关键字  
- 请求：现有 `GET /api/assets`，参数 `status=NORMAL`，可选 `categoryId`、`q`  
- 不传 `characterFilter` / `characterId`  
- 变更筛选立即重新拉取；本期不分页

### 4.3 网格与选择

- 缩略图 + 显示名；点击切换勾选  
- 打开弹窗时以当前已选/已关联 id 预勾选  
- 底栏：已选数量、取消、确定  
- 确定：关闭弹窗并写回本地 `selectedLibraryIds`（或等价状态）；不自动调用保存关联 API

### 4.4 非目标（挑选）

- 不抽到组合/本体  
- 不新增缩略图专用端点  
- 不在选项下拉里塞小图

## 5. 删人物与幽灵关联

### 5.1 行为

`CharacterService.delete(id)`：

1. 取该人物全部 `asset_character_rel` 对应素材  
2. 若存在任一 `status=NORMAL` → `409 Conflict`，文案仅列 NORMAL 素材 id  
3. 否则（无关联，或仅 DELETED）→ 删除该人物全部 `asset_character_rel`，再删人物行

### 5.2 展示

- `listAssets`（人物侧）仍只返回 NORMAL，与现网一致  
- 本期不在编辑页展示「回收站关联」

### 5.3 测试

- 仅挂 DELETED 素材的人物 → 删除成功，rel 清空  
- 挂 NORMAL 素材 → 仍 409  
- 身高边界：null / 合法 / 非法

## 6. 验收标准

1. 可保存/展示人物身高（含空）；非法值拒绝  
2. 人物编辑可按分类+关键字筛选并看见小预览图多选素材；确定后「保存关联」写库成功  
3. 「熊猫头」类仅幽灵 DELETED 关联的人物可删除成功  
4. 仍有 NORMAL 关联时删除仍失败且提示可见素材

## 7. 非目标

- 通用 AssetPicker 组件推广到组合/本体  
- 素材进回收站自动断人物关联  
- 按身高筛选人物  
- 挑选列表服务端分页 / 缩略图 CDN
